Overview

opencode-pi is a local AI gateway on a Raspberry Pi. The opencode agent points its OpenAI-compatible provider at the gateway's /v1 endpoint (localhost:8080 /v1/chat/completions, bearer INFERENCE_API_KEY) and the gateway runs llama-server (llama.cpp) inside its Docker container to serve Qwen3-1.7B (4-bit Q4_K_M, context 32768).
  • Control plane — admin API under /api/* plus the realtime /ws stream; key via x-api-key.
  • Inference plane — OpenAI-compatible /v1/*; key via Authorization: Bearer or x-api-key.
  • Provisioning — scripts/install.sh installs llama-server + the 4-bit model, scripts/update.sh swaps llama.cpp and the model, scripts/cleanup.sh removes old artifacts.
  • Storage — model GGUF lives on NVMe at /opt/qwen-model, mounted into the container at /models. A warehouse SQLite store is planned on NVMe too (PRD §6.13).
  • Analytics — metrics/sparkline sampling is live under /api/metrics; feature/embedding analytics is a planned microservice.
